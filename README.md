# TechZone Professional — GitHub Pages

Proyecto universitario ficticio de una tienda tecnológica completamente compatible con GitHub Pages.


## Archivos requeridos
- `index.html`
- `styles.css`
- `script.js`
- `README.md`

Todos deben permanecer juntos en la raíz del repositorio. No se requiere ninguna carpeta adicional.

## Actualización de pantallas
- Sección educativa sobre LCD, IPS, TN, VA, OLED y Mini-LED.
- Touch screen y digitizer.
- Inverter y controladores de iluminación.
- Color gamut.
- 60 pantallas a la venta: 10 por cada tecnología.
- Cada pantalla muestra Pixel Density (PPI), Refresh Rate (Hz), Screen Resolution y Color Gamut.
- Carrito, favoritos, comparador, filtros y detalles compatibles con los nuevos productos.
- Las fotografías suministradas están integradas directamente en el código; los productos restantes conservan respaldo automático cuando una fuente externa no carga.

## Publicar en GitHub Pages
1. Sube los cuatro archivos a la raíz del repositorio.
2. Abre **Settings → Pages**.
3. Selecciona **Deploy from a branch**.
4. Escoge `main` y `/root`.
5. Guarda los cambios.

Los precios, inventario, reseñas y nombres de productos son demostrativos.


## Imágenes de productos
Las fotografías suministradas por el usuario están integradas como Base64 en `script.js` e `index.html`. Los modelos TechZone demostrativos conservan imágenes representativas y una alternativa integrada cuando corresponde.
